==================================================
  دليل بناء التطبيق (Setup.exe)
  نظام إدارة عيادة الأسنان
==================================================

الهدف:
  توليد ملف Setup.exe واحد لتوزيعه على العيادات.

المتطلبات على جهازك (جهاز المطور):
  - Node.js 20+ (من https://nodejs.org)
  - اتصال إنترنت (لتحميل Electron و electron-builder)

--------------------------------------------------
خطوات البناء:
--------------------------------------------------

1) افتح موجه الأوامر (Command Prompt) في مجلد المشروع.

2) ثبّت المكتبات لأول مرة:
     npm install

3) شغّل أمر البناء:
     npm run build:desktop

4) انتظر حتى ينتهي البناء (2-5 دقائق).

5) ستجد ملف Setup.exe في مجلد release/:
     release\SmileClinic-Setup-1.0.0.exe

6) انسخ هذا الملف ووزّعه على العيادات.

--------------------------------------------------
ملاحظات:
--------------------------------------------------

- ملف Setup.exe هو الملف الوحيد الذي يحتاجه موظف العيادة.
  عند تشغيله سيظهر معالج تثبيت عادي (Next, Next, Finish).

- بعد التثبيت، سيظهر اختصار "Smile Clinic System" على سطح المكتب
  وقائمة ابدأ. عند فتحه يظهر التطبيق كنافذة عادية بدون متصفح.

- يجب وضع أيقونة التطبيق في:
    build/icon.ico
  (أيقونة بحجم 256x256 بكسل بصيغة ICO).
  إذا لم تُوجد، سيستخدم electron-builder أيقونة افتراضية.

- لتغيير اسم التطبيق أو الإصدار، عدّل ملف:
    electron-builder.yml

- لاختبار التطبيق قبل البناء:
     npm run dev:electron
  (يفتح نافذة Electron مع خادم التطوير)

--------------------------------------------------
مشاكل شائعة:
--------------------------------------------------

- "electron-builder not found":
     npm install electron-builder --dev

- "icon.ico not found":
  ضع أيقونة في build/icon.ico أو احذف سطر icon من electron-builder.yml.

- بطء البناء أول مرة:
  طبيعي — electron-builder يحمّل أداة بناء NSIS مرة واحدة فقط.
