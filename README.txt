==================================================
  نظام إدارة عيادة الأسنان
  دليل الاستخدام
==================================================

ما هو هذا النظام؟
  نظام متكامل لإدارة عيادة الأسنان يعمل بالذكاء
  الاصطناعي المحلي (بدون إنترنت بعد التثبيت).

الملفات الرئيسية:
  - setup-and-run.bat : التثبيت والتشغيل بنقرة واحدة
  - backup.bat        : النسخ الاحتياطي للبيانات
  - uninstall.bat     : إزالة النظام بالكامل
  - config.json       : إعدادات النظام (منافذ، ذكاء اصطناعي)
  - install-guide.txt : دليل التثبيت السريع

كيف أبدأ؟
  اضغط مرتين على setup-and-run.bat وانتظر.

كيف أوقف النظام؟
  أغلق نافذة "جسر Ollama المحلي".

كيف أعيد التشغيل؟
  شغّل setup-and-run.bat مرة أخرى.

كيف أنشئ نسخة احتياطية؟
  شغّل backup.bat.

كيف أصل من هاتفي؟
  تأكد أن هاتفك على نفس شبكة WiFi.
  اكتب في المتصفح: http://[IP-الكمبيوتر]:5173

إعدادات متقدمة (config.json):
  - ports.bridge : منفذ الجسر (افتراضي 3001)
  - ports.web    : منفذ النظام (افتراضي 5173)
  - ollama.models : النماذج المحملة
  - ai.provider  : "local" للذكاء المحلي، "cloud" للسحابة
  - api_keys     : مفاتيح API للخدمات السحابية (اختياري)
